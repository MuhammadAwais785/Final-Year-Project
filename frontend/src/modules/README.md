# Mobile modules

Har module SRS ke corresponding feature area ko contain karta hai:

- `m01_onboarding`: guardian/child profile aur language selection
- `m02_avatar`: doctor avatar aur TTS
- `m03_games`: learning games
- `m04_speech_ai`: keyword spotting aur clarity score
- `m05_vision_ai`: emotion/stress analysis
- `m06_difficulty`: adaptive level scaling
- `m07_intervention`: calming breaks aur alerts
- `m08_sync`: offline queue/background sync
- `m09_dashboard`: parent analytics
- `m10_reports`: PDF reports
